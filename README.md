## 👨‍💻 About Me

Senior AI Full Stack Engineer with 15+ years of experience designing and delivering enterprise software across AI, cloud, and modern web technologies.

I specialize in building intelligent applications powered by LLMs, RAG pipelines, real-time data streaming, and cloud-native architectures. My experience spans scalable backend systems, modern frontend applications, distributed event-driven platforms, and DevOps automation across AWS, Azure, and GCP.

My focus is building software that is reliable, maintainable, and capable of operating at production scale.

- AI-powered applications with OpenAI, Claude, Gemini, LangChain, and LangGraph
- Production RAG systems, vector search, and multi-agent architectures
- Cloud-native backend services using Python, Node.js, FastAPI, and NestJS
- Modern frontend development with React, Next.js, and TypeScript
- Distributed systems, event streaming, and microservices
- CI/CD, Kubernetes, Docker, and cloud infrastructure automation

> [!NOTE]
> I enjoy solving complex engineering challenges by combining AI, distributed systems, and modern cloud technologies into production-ready solutions.
